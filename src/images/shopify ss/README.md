- File names: `shopify1.jpg`, `shopify2.jpg`, `shopify3.jpg`, `shopify4.jpg`, `shopify5.jpg`
- **Exactly 5 slides.** The slider shows these 5 and rotates every 5 seconds.

- Landscape screenshots look best (wide Shopify Admin tables).
