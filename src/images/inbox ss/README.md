# Inbox screenshots

Client testimonial screenshots shown in a responsive gallery inside the
Testimonials section. All supported image files in this folder are registered
automatically; the gallery displays 10 at first and reveals more on request.

- File names can be descriptive and do not need a numbered prefix.
- Images are sorted by filename, with numeric portions in natural order.
- Preserve each screenshot's original aspect ratio; portrait and landscape files are supported.
- Supported: `.jpg` `.jpeg` `.png` `.webp` `.avif`
