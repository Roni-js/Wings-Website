## 🚀 About The Project

**Wings Marketing** is a modern, responsive website developed for a digital marketing agency specializing in creative branding, online marketing, and business growth.

The website focuses on delivering a premium digital experience through modern UI design, responsive layouts, interactive components, and smooth animations.

The project was **developed by Ronodip Sill**, combining modern frontend technologies with creative design principles to build an engaging agency website.

### 🎯 Project Goals

- Build a modern and professional agency website.
- Deliver a clean and premium user interface.
- Create a responsive experience across devices.
- Implement smooth transitions and engaging animations.
- Highlight digital marketing services effectively.
- Provide intuitive navigation and a polished user experience.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Roni-js/Wings-Website.git
```

### 2. Navigate to the Project

```bash
cd Wings-Website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

Open the local address shown in your terminal.
